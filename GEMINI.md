# Project Guidelines & Git Workflow

## Git & Deployment Rules
1. **Never push directly to `main`:**
   - Always commit and push to a feature or working branch (e.g. `feat/*`, `fix/*`).
   - Never merge into `main` or execute `git push origin main` unless the user explicitly asks to merge/push to `main`.
   - Always open/propose a Pull Request or request user approval before any production or `main` branch update.
